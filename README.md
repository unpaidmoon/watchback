# Watchback

Watchback 是一款面向 Windows 的《守望先锋》本地数据分析桌面应用。它可以将网易大神中的赛季数据同步到电脑，在一个清晰、连贯的界面中查看对局记录、个人表现、英雄与地图统计，以及队友和角斗数据。

数据分析主要在本机完成。同步后的历史数据保存在本地，即使暂时无法连接上游服务，已经保存的内容仍可继续查看。

## 功能亮点

- **赛季数据同步**：登录网易大神后，按赛季更新对局列表与详情，并在后台继续补全数据。
- **对局记录**：按赛季、英雄、地图、胜负、模式和日期筛选，快速定位想复盘的比赛。
- **对局详情**：查看双方玩家表现、同职责赛季均值对比，以及普通模式和角斗模式的详细数据。
- **个人战报**：汇总赛季对局、胜率、常用英雄、职责段位和选择倾向。
- **英雄与地图排行**：查看英雄胜率、地图胜率及样本量，并按名称搜索。
- **好友分析**：基于本地赛季数据了解常见队友、配合表现和地图表现。
- **角斗支持**：展示角斗竞技与快速模式数据，包括装备、异能和分轮详情。
- **多赛季本地管理**：分别查看和更新受支持赛季的数据，避免不同赛季的统计混在一起。

## 系统要求

- Windows 10 或 Windows 11。
- Chrome 或 Microsoft Edge，用于完成网易大神登录。
- 可用的网易大神账号，并已关联需要同步的《守望先锋》账号。
- 同步数据时需要网络连接；查看已经保存的本地数据通常不需要重新同步。

Watchback 当前以 Windows 桌面版为主要产品形态，暂不提供 macOS、Linux 或网页版。

## 安装与首次使用

目前仓库没有提供公开下载地址。取得 Watchback 安装包后：

1. 运行安装程序并启动 Watchback。
2. 在指挥台选择“登录网易大神”。
3. 按提示在 Chrome 或 Edge 中完成登录，等待 Watchback 确认当前账号。
4. 选择需要的赛季并开始更新。应用会先获取可用的对局列表，再在后台补全详情。
5. 同步后可从对局、复盘和排行等页面查看本地数据。

首次完整同步所需时间取决于赛季对局数量和上游服务响应速度。同步期间请保持应用运行；部分详情暂时失败时，可以稍后重试。

## 数据目录与隐私

- Windows 安装版把 Watchback 自有的可写业务数据保存在安装目录下的 `data\`。账号数据、对局数据、设置、同步状态、浏览器登录 profile、诊断和备份都位于此目录。
- 静态图片、图标和字典随应用正式打包，不复制到 `data\`。Windows、WebView2 和安装器仍可能使用系统管理的临时目录或运行时缓存。
- 旧版 `%APPDATA%\local.owstats.desktop` 只会在 NSIS 提升安装迁移时作为只读来源；正常桌面运行不会读写该目录。
- Watchback 不提供云端账号系统，也不会把本地数据库作为产品数据上传到项目仓库。
- 登录凭据仅用于访问当前登录账号对应的上游数据；应用不会主动把凭据复制到无关的账号索引、界面事件或诊断日志。
- 上游返回的业务数据和错误信息会按原始内容保存在本地，以保证导入、查询和故障排查的一致性。
- 不要公开分享安装目录中的 `data\`、浏览器登录资料、本地数据库或同步产生的原始数据文件。

## 常见问题

### 点击登录后没有打开浏览器

请确认已经安装 Chrome 或 Microsoft Edge，然后重新尝试登录。

### 已经登录，但无法同步

确认网易大神账号已关联正确的《守望先锋》账号。如果登录状态或凭据已失效，请在 Watchback 中选择“重新登录”后再试。

### 更新完成后，部分对局详情仍未出现

Watchback 会先更新对局列表，再在后台补全详情。请保持应用运行并稍后查看；遇到临时网络或上游错误时，可以重新更新该赛季。

### 没有网络时还能使用吗

可以继续查看已经保存到本机的数据。登录、更新赛季和补全缺失详情仍需要网络连接。

### 卸载应用会删除本地数据吗

默认卸载会保留安装目录中的 `data\`，以免误删账号凭据、数据库、赛季数据、备份和浏览器登录状态。只有在卸载界面明确选择“同时删除本地数据”后才会删除该精确目录；保留数据时安装目录可能不会被完全移除。

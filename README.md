# Watchback

Watchback 是一款面向 Windows 的《守望先锋》本地战绩与复盘工具。它可以把网易大神中的赛季数据同步到电脑，用统一的界面浏览对局、分析个人表现、查询玩家，并查看英雄、地图、队友和角斗数据。

数据分析主要在本机完成。同步后的历史数据保存在本地，即使暂时无法连接上游服务，已经保存的内容仍可继续查看。

当前版本：`0.3.0-beta.2`。


## 功能亮点

- **二维码登录与多账号管理**：使用网易大神 App 扫码添加账号，也可切换到浏览器登录；不同账号的凭据和本地数据相互隔离。
- **赛季同步与自动更新**：按赛季全量抓取或增量更新对局；默认在启动时检查已有数据中的最新赛季，可在指挥台关闭。这里的自动更新仅指赛季数据，不是应用版本更新。
- **对局记录**：按赛季、英雄、地图、胜负、模式、日期和收藏状态筛选，并可为重要对局添加收藏和备注。
- **AI 锐评**：配置自己的 DeepSeek API Key 后，可根据匿名化的本场数据生成复盘锐评。
- **玩家查询**：通过 BattleTag 即时查看玩家资料、段位、常用英雄和最近对局；查询结果只用于当前会话，不会写入本地历史数据库。
- **战报、成就与排行**：汇总赛季胜率、常用英雄、职责段位、队友协作、高胜率选择和生涯成就，并提供英雄与地图排行。
- **角斗支持**：展示角斗竞技与快速模式数据，包括装备、异能和分轮详情。

## 系统要求

- Windows 10 或 Windows 11。
- Chrome 或 Microsoft Edge，作为登录流程所需的浏览器运行环境。
- 推荐安装网易大神 App，以便扫描应用内显示的登录二维码。
- 可用的网易大神账号，并已关联需要同步的《守望先锋》账号。
- 登录、同步、玩家查询和 AI 锐评需要网络连接；查看已保存的本地数据通常不需要重新联网。
- AI 锐评为可选功能，需要用户自行提供有效的 DeepSeek API Key。

Watchback 当前仅提供 Windows 桌面版，不提供 macOS、Linux 或网页版。

## 安装与首次使用

请从 [GitHub Releases](https://github.com/fengpianpianne/watchback/releases) 下载 Windows 安装包，并核对发行页提供的 SHA-256 哈希。下载后：

1. 运行安装程序并启动 Watchback。
2. 打开“指挥台”，选择“添加账号”。
3. 使用网易大神 App 扫描二维码并在手机上确认登录；二维码不可用时，可选择“其他登录方式”改用 Chrome 或 Edge。
4. 确认应用识别到的《守望先锋》账号，选择目标赛季并执行一次“全量抓取”。
5. 等待应用先保存对局列表，再在后台补全详情。之后可从“对局”“查询”“战报”“成就”和“排行”页面查看数据。

首次完整同步所需时间取决于赛季对局数量和上游服务响应速度。同步期间请保持应用运行；部分详情暂时失败时，可以稍后重试。完成首次同步后，默认启用的赛季自动更新会在后续启动时检查已有数据中的最新赛季。

## 本地数据与隐私

- Windows 安装版把 Watchback 自有的可写业务数据保存在安装目录下的 `data\`。账号凭据、对局数据、设置、同步状态、浏览器登录 profile、诊断和备份都位于此目录。
- 每个账号使用独立的凭据和本地数据库。切换账号不会混用数据；在账号管理中“永久退出账号”会删除该账号保存的凭据和数据库，且无法撤销。
- 静态图片、图标和字典随应用正式打包，不复制到 `data\`。Windows、WebView2 和安装器仍可能使用系统管理的临时目录或运行时缓存。
- Watchback 不提供云端账号系统，也不会把本地数据库作为产品数据上传到项目仓库。
- 登录凭据仅用于访问当前登录账号对应的上游数据，不会主动复制到界面事件、诊断日志或无关数据结构。
- 玩家即时查询的数据只保留在当前查询会话中，不会写入本地历史数据库。
- 使用 AI 锐评时，只会发送匿名英雄阵容、计分板、派生指标和回合趋势；不会发送玩家名称、玩家 ID、备注、原始 JSON、对局 ID 或登录凭据。
- 上游返回的业务数据和错误信息会按原始内容保存在本地，以保证导入、查询和故障排查的一致性。
- 不要公开分享安装目录中的 `data\`、浏览器登录资料、本地数据库或同步产生的原始数据文件。

## 常见问题

### 二维码没有显示，或者扫码登录失败

确认已经安装 Chrome 或 Microsoft Edge，然后刷新二维码重试。仍无法登录时，选择“其他登录方式”，按提示在浏览器中完成登录。

### 已经登录，但无法同步

确认网易大神账号已关联正确的《守望先锋》账号，并按应用提示确认检测到的 BattleTag。如果登录状态或凭据已失效，请在账号管理中重新添加或更新该账号。

### 更新完成后，部分对局详情仍未出现

Watchback 会先更新对局列表，再在后台补全详情。请保持应用运行并稍后查看；遇到临时网络或上游错误时，可以重新更新该赛季。

### 自动更新为什么没有获取新赛季

赛季自动更新只检查本地已有数据中的最新赛季。首次使用或需要添加新赛季时，请先在指挥台选择目标赛季并执行全量抓取。

### AI 锐评无法生成

请先在指挥台保存并验证 DeepSeek API Key，再检查网络、Key 是否有效以及账户余额。AI 锐评不影响其他本地分析功能。

### 没有网络时还能使用吗

可以继续查看已经保存到本机的数据。登录、更新赛季、查询其他玩家和生成 AI 锐评仍需要网络连接。

### 卸载应用会删除本地数据吗

默认卸载会保留安装目录中的 `data\`，以免误删账号凭据、数据库、赛季数据、备份和浏览器登录状态。只有在卸载界面明确选择“同时删除本地数据”后才会删除该目录；保留数据时安装目录可能不会被完全移除。

# Local Data

This directory is for local runtime data only. Do not commit credentials, browser profiles, downloaded assets, or API cache files.

Common local-only contents:

- `.dashen_credentials.json`: local NetEase Dashen sync credential cache.
- `chrome-dashen-profile/`: browser profile used by desktop login.
- `assets/`: downloaded image/cache assets.
- `ow_config_cache.json`: local API configuration cache.

Keep this README so the directory purpose is visible in the repository.

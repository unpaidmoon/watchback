# 对局详情收藏按钮对齐设计

## 目标

在宽屏对局详情中保持两个收藏操作按钮的既有高度和间距，仅将按钮组整体上移，使其上沿与左侧备注输入框上沿对齐。

## 范围

- 仅调整 `MatchFavoriteEditor` 的样式。
- 不修改收藏、取消收藏、保存备注、禁用状态或提示文本。
- 不修改按钮高度、输入框高度、颜色、圆角或间距令牌。
- 窄屏下继续使用现有的横向双按钮布局，不额外增加纵向偏移。

## 实现

宽屏下让 `.matchFavoriteActions` 从编辑器网格顶部开始定位，并使用“标签行高 + 标签到输入框的间距”作为顶部偏移。这样按钮组的上沿会落在备注输入框的上沿，而不是与包含字数统计的整个备注字段底部对齐。

在现有 `max-width: 1099px` 响应式规则中清除该顶部偏移，保留按钮组位于备注字段下方的既有布局。

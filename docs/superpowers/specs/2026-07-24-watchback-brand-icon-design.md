# Watchback 品牌名称与图标设计

## 目标

为 OWStatsLocal 建立正式的产品名称与图标体系，使其在 Windows 桌面、任务栏、安装包、启动页和项目介绍中具备稳定且一致的品牌识别。

品牌首先表达“自动记录整个赛季，并帮助玩家回望成长的私人战斗手账”。图标不承担解释全部产品功能的任务，而应优先做到轮廓清楚、容易记忆、气质一致，并能在小尺寸下辨认。

## 品牌名称

正式英文名称为：

> **Watchback**

首次介绍产品、启动页与项目主页可使用中文功能说明：

> **守望战绩工具**

标准组合写法为：

> **Watchback**  
> 守望战绩工具

品牌名称不刻意嵌入或突出 `OW`，图形也不隐藏 `OW` 字母。与《守望先锋》的领域关联由中文功能说明、产品内容与使用场景承担。

设计不得模仿《守望先锋》的官方徽记、英雄、武器、字体或既有视觉资产，也不得形成官方产品的暗示。

## 品牌性格

Watchback 是一名“认真可靠的私人赛季记录员”：

- 温和、有生命力，但不幼稚。
- 认真、专注，但不严肃冷漠。
- 强调长期记录、回望和成长，不强调胜负刺激。
- 不使用电竞战队式的尖角、火焰、霓虹和高饱和渐变。

角色可以出现在应用图标、启动页、关于页面、空状态与项目介绍中。常规数据界面继续遵循 `design.md` 的克制桌面工具语言，不因吉祥物引入大面积卡通装饰。

## 核心角色

品牌主角是一本拟人化的战斗手账。

### 外形

- 主体为略厚的软皮手账，轮廓接近圆角竖矩形。
- 封面使用深炭灰，纸页侧边为暖白。
- 跑动时纸页可以轻微扇开，形成克制的速度感。
- 封面上有一双小而专注的眼睛。
- 嘴部表情保持克制，不使用夸张大笑或慌张表情。
- 角色有短手和短腿，手中抱着一支记录笔。

### 标志性动作

角色向前跑，同时回头查看身后的比赛轨迹：

- 身体和腿朝向前进方向。
- 眼睛与封面姿态明确朝后回望。
- 身后延伸一条由短线、圆点和小型数据记号构成的轨迹。
- 轨迹代表过去的比赛，靠近角色处较清楚，远端逐渐简化。

这一动作同时表达 Watchback 的名称、持续前进和从历史对局中观察成长，是品牌最重要的识别资产。

## 视觉风格

采用克制的手绘吉祥物风格：

- 扁平矢量结构。
- 大色块和清楚轮廓。
- 轮廓允许轻微不规则，保留人工绘制感。
- 不依赖纹理、复杂光影或细碎装饰。
- 动作具有叙事性，但变形程度低于夸张卡通 Logo。
- 角色在没有文字时也应具有独立辨识度。

参考图只用于确定“有性格的主角 + 标志性动作 + 手绘字标”的设计方法，不复制其动物、动作、造型、配色或字体。

## 配色

品牌配色继承现有产品视觉令牌，不新增品牌色：

| 用途 | 色值 |
|---|---|
| 手账封面、深色图标底 | `#303030` |
| 纸页、浅色细节 | `#F4F6F0` |
| 轨迹、局部动作提示 | `#86B8B4` |
| 少量数据节点 | `#4B22D1` |
| 浅色展示背景 | `#E3E8E2` |

紫色只用于少量数据节点或可见焦点，不成为角色主体色。不得引入黄色爆炸形、橙红高光、霓虹渐变或新的高饱和品牌色。

## 完整 Logo

完整 Logo 用于启动页、关于页面、项目主页和宣传图。

### 构图

- 使用横向或略带对角线的动态构图。
- 左后方为逐渐简化的比赛轨迹。
- 中部为向右跑、同时回头的手账角色。
- `Watchback` 英文字标置于图形下方或右下方。
- 中文功能说明可作为独立的第二行，不与角色轮廓重叠。

### 字标

- `Watchback` 可使用与角色一致的轻微手绘字形。
- 字形必须保持清楚、稳定，避免儿童涂鸦感。
- 中文功能说明使用项目现有系统无衬线字体，不模仿手写。
- 不使用《守望先锋》官方字体或近似字形。

## 应用图标

应用图标是同一角色的紧凑近景版本，不是完整 Logo 的机械缩小。

### 构图规则

- 角色占画面约七成。
- 突出手账封面、眼睛和回头方向。
- 只保留一支笔与一小段弧形轨迹。
- 去除完整跑步场景、长轨迹、英文名称和中文说明。
- 优先使用深色角色配浅色背景；同时验证深炭灰圆角方形底的反转版本。
- 不增加描边、阴影或高光来弥补小尺寸识别问题，应通过轮廓和明暗关系解决。

### 小尺寸要求

分别针对 `16`、`24`、`32`、`48`、`64`、`128` 和 `256px` 检查：

- 手账主体仍可辨认。
- 回头的视线方向仍然成立。
- 冷蓝绿轨迹不会变成模糊色块。
- 笔与纸页若在当前尺寸不可辨认，应在对应尺寸版本中删除或简化。
- `16px` 版本只需保留“深色手账角色 + 朝后视线 + 冷蓝绿轨迹”的核心识别。

## 交付物

品牌设计阶段最终应产出：

- 完整横向 Logo。
- 无中文副标题的 Logo。
- 正方形应用图标。
- 透明背景版本。
- 深色背景与浅色背景预览。
- 可继续编辑的 SVG 主文件。
- Windows 所需尺寸的 PNG 与 ICO。

图像草案应先验证角色、动作和轮廓，再处理字标与尺寸导出。未经确认的生成图不得直接替换仓库中的正式图标。

## 验收标准

- 用户第一眼能感受到一个认真记录并回望过去的角色。
- 不依赖 `OW` 字母、官方徽记或游戏资产也能形成独立识别。
- 完整 Logo 的动作在不读文字时仍然成立。
- 应用图标在 Windows 任务栏常见尺寸下具有清晰轮廓。
- 配色与 `design.md` 一致，没有新增品牌色。
- 角色不会使常规数据界面变成卡通主题。
- 所有可见文字均符合中文产品界面要求，英文品牌名除外。
- 不包含真实用户数据、凭据、隐私标识或开发机路径。

## 非目标

- 本设计不重构现有页面视觉体系。
- 本设计不为常规页面增加大面积角色插画。
- 本设计不使用或修改《守望先锋》官方资产。
- 本设计不在当前阶段修改 Tauri 标识、安装包资源或应用内名称。

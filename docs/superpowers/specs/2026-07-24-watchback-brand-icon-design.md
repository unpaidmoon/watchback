# Watchback 品牌名称与图标设计

## 目标

为 OWStatsLocal 建立正式的产品名称与图标体系，使其在 Windows 桌面、任务栏、安装包、启动页和项目介绍中具备稳定、专业且独立的品牌识别。

图标不承担解释全部产品功能的任务。它应优先做到：

- 使用尽可能少的构造形成独特轮廓。
- 在黑白状态下成立。
- 在 `16px` 到 `256px` 的 Windows 常见尺寸中保持辨识度。
- 与现有灰绿画布、深炭灰文字和紫色数据强调相容。
- 不依赖阴影、渐变、纹理或复杂插画制造质感。

## 品牌名称

正式英文名称为：

> **Watchback**

中文功能说明为：

> **守望战绩工具**

标准组合写法为：

> **Watchback**  
> 守望战绩工具

品牌名称不嵌入或突出 `OW`。与《守望先锋》的领域关联由中文功能说明、产品内容与使用场景承担。

品牌不得模仿《守望先锋》官方徽记、英雄、武器、字体或既有视觉资产，也不得形成官方产品的暗示。

## 品牌性格

Watchback 的品牌气质是：

- 克制、专业、安静。
- 具有技术精度，但不过度冰冷。
- 强调长期记录、回望和成长，不强调竞技刺激。
- 依靠比例、留白和构造秩序表达高级感。

不得使用吉祥物、拟人角色、手绘插画、电竞战队式尖角、火焰、霓虹或高饱和渐变。

## 核心标志

核心标志采用 B2「渐进流动」时间切片。

### 构造

- 标志由三条不闭合的弧形切片与一个独立圆形节点组成。
- 三条切片使用相同视觉粗细和相同端点形式。
- 切片由内向外逐层展开，外层范围最大，内层范围最小。
- 三层保持清楚的负空间，不连接、不交织、不形成花结。
- 外层右上端附近设置独立圆形节点。
- 所有切片端点使用圆头。
- 整体视觉重心位于画布中心略偏左下，节点平衡右上留白。

### 含义

- 内层代表较早的比赛记录。
- 中层代表持续积累的赛季过程。
- 外层代表向前延伸的成长轨迹。
- 右上节点代表当前时刻。

含义不需要用户首次看到时完整解读；首要目标是形成稳定、可记忆的抽象标志。

### 原创性边界

标志只借鉴成熟软件品牌常见的设计纪律：固定比例、明确留白、黑白优先和矢量构造。

不得使用或近似复刻：

- OpenAI 的交织花结结构。
- Claude 或 Anthropic 的星芒、放射或字母结构。
- Codex、ChatGPT 或其他 OpenAI 产品的既有产品标志。
- 任何第三方品牌的具体轮廓、节点排列或负形。

## 几何规范

### 基础画布

- SVG 使用 `96 × 96` 逻辑画布。
- 标准标志的安全区为画布四周至少 `12` 个逻辑单位。
- 标志不得触碰安全区。

### 标准路径

标准结构以以下几何关系为基准：

- 外层从右上向左上、左侧、左下和右下展开，形成最大的不闭合弧。
- 中层与外层保持近似平行的视觉节奏，开口方向一致。
- 内层保留最短弧段，不能缩成孤立逗号。
- 三层之间的最小负空间不得小于标准笔画粗细的 `0.7` 倍。
- 标准笔画粗细为 `10` 个逻辑单位。
- 标准端点为圆头。
- 节点直径为 `10` 个逻辑单位。

最终 SVG 可进行不超过 `1` 个逻辑单位的光学校正，以解决数学居中与视觉居中的差异。校正不得改变三层渐进展开的结构。

### 小尺寸版本

`16px` 和 `24px` 使用单独的简化版本：

- 笔画可增加至相对画布约 `11–12%`。
- 负空间必须保持打开，不能糊成实心块。
- 节点可以略增大，但不得与外层切片接触。
- 必要时缩短内层弧，不能删除整个层级。
- 不使用描边外的阴影或锐化效果补偿可读性。

`32px` 及以上使用标准结构。

## 配色

标准配色采用 C2「紫色当前节点」：

| 用途 | 色值 |
|---|---|
| 标准路径 | `#202220` |
| 当前节点 | `#4B22D1` |
| 暖白背景 | `#F4F6F0` |
| 灰绿背景 | `#E3E8E2` |
| 反白路径与节点 | `#F4F6F0` |

规则：

- 紫色只用于独立节点，不用于三条切片。
- 标准 Logo 优先放在暖白或灰绿背景。
- 单色版本将路径与节点统一为 `#202220`。
- 深色背景版本将路径与节点统一为 `#F4F6F0`。
- 不使用渐变、透明度、阴影、发光、纹理或多色切片。

## 字标

完整 Logo 由核心标志与 `Watchback` 字标组成。

- 字标使用中性、现代、几何感适中的无衬线字形。
- 不引入在线字体或第三方字体运行时依赖。
- 正式 SVG 中将确认后的英文字标转换为路径，避免字体环境差异。
- 字标不得模仿 OpenAI Sans、Anthropic 字标或《守望先锋》官方字体。
- 字标与标志之间保持至少一个标准笔画粗细的间距。
- 英文字标可横向置于标志右侧，也可置于标志下方；标准版本优先横向组合。

中文功能说明 `守望战绩工具` 是可选第二层：

- 使用项目现有系统字体栈。
- 字重为 `400`。
- 不转换为手写体，不与英文字标争夺视觉层级。
- 应用图标与紧凑 Logo 不包含中文说明。

## 应用图标

应用图标只使用时间切片标志，不使用英文或中文文字。

### 标准版本

- 正方形画布。
- 标志在画布中视觉居中。
- 保留四周安全区。
- 使用深炭灰路径与紫色节点。
- 固定使用暖白 `#F4F6F0` 圆角方形底，保证深色与浅色 Windows 主题下均可辨认。
- 圆角背景属于应用图标专用容器，不加入透明 Logo 与核心标志 SVG。

### 变体

- 标准双色版本。
- 深炭灰单色版本。
- 暖白反相版本。
- `16px` 与 `24px` 专用简化版本。

Windows ICO 至少包含 `16`、`24`、`32`、`48`、`64`、`128` 和 `256px`。

## 交付物

最终品牌资产包括：

- 标准 B2 + C2 核心标志 SVG。
- 单色核心标志 SVG。
- 反白核心标志 SVG。
- `16px` 与 `24px` 简化 SVG。
- 横向英文 Logo SVG。
- 带中文功能说明的标准组合 SVG。
- 透明背景 PNG。
- 暖白与深色背景预览。
- Windows 多尺寸 PNG 与 ICO。
- 几何与配色说明。

不得把生成式图像草案作为最终图标。最终核心标志、字标组合和尺寸变体必须为可检查、可重复导出的矢量资产。

## 验收标准

- 黑白状态下仍具有清楚且稳定的识别。
- 三层切片在 `16px` 下仍能区分。
- 紫色节点在小尺寸下不与外层路径粘连。
- 标志在浅色、深色和透明背景上均有可用版本。
- 不含渐变、阴影、纹理、光效、手绘插画或吉祥物。
- 与 OpenAI、Anthropic、Codex 和《守望先锋》既有标志不存在可混淆的具体轮廓。
- SVG 不嵌入栅格图、脚本、外部字体、网络资源或开发机绝对路径。
- PNG、ICO 和安装包资源不包含真实用户数据、凭据或隐私标识。

## 产品集成

Watchback 品牌资产通过确认后，应同步更新用户可见的产品名称与全局导航品牌区。

### 用户可见名称

- Tauri `productName` 使用 `Watchback`。
- Windows 主窗口标题使用 `Watchback`。
- WebView HTML 标题使用 `Watchback`。
- 全局导航左侧主标题使用 `Watchback`。
- 全局导航左侧副标题使用 `守望战绩工具`。
- 视觉验收 fixture 中的产品名称与品牌区同步使用 Watchback。

### 全局导航品牌区

- 删除现有 `Sparkles` 占位图标。
- 使用正式 B2 + C2 核心标志。
- 图标资源必须由 Vite 正式导入并打包，不使用开发机绝对路径、`/@fs/` 或忽略文件。
- 图标容器使用暖白圆角方形，不使用现有深炭灰圆形底。
- 图标路径保持深炭灰，当前节点保持紫色。
- 图标与文字继续遵循现有 `4 / 8 / 12 / 16 / 24 / 32 / 40px` 间距体系。
- 主标题与副标题保持当前紧凑层级，不扩大导航栏高度。

### 兼容标识

以下内部名称不得随品牌展示名修改：

- Tauri identifier `local.owstats.desktop`。
- SQLite 文件名、数据库路径和应用数据目录。
- Windows Credential Manager 中既有的 `OWStatsLocal` credential target 与用户名。
- Rust crate 名、内部模块名、API 字段名和上游协议字段。

保留这些名称是升级与本地数据兼容要求，不属于用户可见品牌残留。

## 非目标

- 本设计不重构现有页面视觉体系。
- 本设计不在常规页面增加品牌装饰动画。
- 本设计不使用图像模型生成最终标志。
- 本设计不使用或修改《守望先锋》官方资产。
- 本次集成不修改 Tauri identifier、数据库、应用数据目录、凭据服务名、Rust crate 名或内部 API。

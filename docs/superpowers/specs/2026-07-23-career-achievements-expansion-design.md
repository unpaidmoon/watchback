# 生涯成就扩展与详情页精简设计

## 目标

将成就体系从“所选赛季统计”调整为“当前账号的本地生涯累计”，新增 10 组成就，并为每个等级记录首次解锁时间。成就详情页同步精简，只保留成就名称、三级徽章、达成条件和已解锁等级的解锁日期。

本文只定义产品、数据和视觉规则；具体实现另行规划。

## 核心决策

- 所有成就按当前账号的全部已导入赛季统计，不随赛季切换重置。
- 单局表现型成就以历史单局最佳表现决定等级；达到更高阈值后永久解锁对应等级。
- 累计型成就按符合条件的历史对局数或生涯总量决定等级。
- 段位型成就按所有职责中的生涯最高段位决定等级。
- 每个等级的解锁时间为本地已导入数据中首次满足该等级条件的对局日期。
- 若本地未导入完整历史数据，解锁时间只代表“当前已导入记录中的首次达成时间”，不得声称是账号真实首次达成时间。
- 成就墙和详情页不再依赖所选赛季；成就页取消赛季选择器和 `season` 查询参数。
- 新徽章遵循 `docs/season-achievement-badge-production-workflow.md`，正式资源必须是开放式透明底 PNG，背景动态光效不烘焙进徽章。

## 通用统计规则

### 数据范围

- 仅统计当前登录账号本地数据库中已经成功导入的对局。
- 跨所有已导入赛季聚合，但保持账号数据隔离，不跨账号合并。
- 同一 `match_id` 只能计入一次，重复同步不得重复累计成就进度。
- 无法确认当前玩家、统计字段缺失或对局记录无效时，该对局不参与依赖相应字段的成就计算。

### 单局型成就

- “单局伤害、承伤、击杀、助攻、死亡”均使用当前玩家在该场对局中的最终统计。
- 每十分钟数值统一按 `原始数值 ÷ 有效对局秒数 × 600` 计算。
- 每十分钟类成就只统计有效时长不少于 300 秒的对局，避免极短对局放大比率。
- 原始时长缺失、为零或明显无效的对局不参与每十分钟类成就。
- 单局型三级条件表示三个逐渐提高的表现门槛，不按达标次数升级。
- 达成日期取按时间升序扫描时，第一场满足对应等级条件的对局 `begin_ts`。

### 累计型成就

- 按 `begin_ts` 升序累计有效对局。
- 解锁日期取累计值首次达到对应阈值的那场对局日期。
- 与好友游戏场数按对局去重：一场中存在至少一名被识别为好友的同队玩家即计 1 场，不按好友人数重复累计。

### 段位型成就

- 比较当前玩家全部已导入对局中的有效竞技段位记录。
- 坦克、输出和支援三个职责共享一个生涯最高段位；任一职责达到门槛即可解锁。
- 同一段位内的子段位不影响本成就等级。
- 解锁日期取首次出现相应或更高段位记录的对局日期。
- 缺少段位记录时保持未解锁，不以 MMR 或推测段位替代。

### 解锁稳定性

- 只要对应历史达成证据仍存在于本地数据库，已解锁等级不得因切换页面、切换赛季或重新同步而回退。
- 数据重新导入后必须通过确定性的历史扫描得到相同等级和解锁日期。
- 如果用户主动删除了唯一的历史达成对局，本地重算结果可以回退；本设计不新增脱离原始证据的永久云端成就账本。

## 现有成就的生涯化与删除

现有成就中的“巅峰一战”完整删除：不进入生涯成就列表，不计算等级或解锁日期，并移除 `peak` key 的前端配置与三级徽章资源。

其余 7 组成就继续保留原名称、key、徽章和三级阈值，但统计范围从所选赛季改为当前账号的全部已导入生涯数据：

- `win-streak`：跨赛季逐场扫描，但连胜不得跨越赛季边界或不连续时间段直接拼接；每个赛季独立计算后取生涯最长值。
- `win-rate`：生涯全部有效胜负对局计算胜率；现有样本门槛如后续实现需要，应在实现计划中明确。
- `s-grade`、`carry`、`signature`：累计全部已导入赛季的对应高光记录。
- `hero-focus`：按生涯英雄使用场数计算第一英雄占比。
- `switching`：按生涯实际使用过的不同英雄数计算。

现有成就也要为 `I / II / III` 分别回算首次解锁日期，不允许使用当前时间伪造解锁日期。

- 页面标题继续使用“成就”。
- 页面说明改为“生涯成就与进度”。
- 移除赛季选择器。
- 成就页不再读取、写入或保留 `season` 查询参数。
- 从其他页面进入成就页时统一导航到 `/achievements`。
- 成就墙的卡片布局、透明徽章、二级紫蓝动态光效、三级金色动态光效和未解锁暗处理保持现有规则。

- 卡片仍只显示当前等级徽章、成就名称和简短说明。
- 解锁日期不放在成就墙卡片上，避免增加卡片高度和信息噪声。
- 单击卡片打开对应成就详情。
- 鼠标悬停的浅灰状态继续仅存在于成就墙；点击后不保留选中底色。

## 成就详情页调整

### 顶部

- 只保留成就名称作为详情主标题。
- 删除“成就详情”眉题。
- 删除主标题下方的当前指标或说明文字，例如“146 胜 / 137 负”。
- 关闭按钮、对话框语义、焦点管理和键盘关闭行为保持不变。

### 等级展示

每个等级区域按以下顺序显示：

1. 徽章与对应动态光效。
2. 罗马等级 `I / II / III`。
3. 该等级的完整达成条件。
4. 已解锁时显示 `YYYY.MM.DD 解锁`。

未解锁等级不显示占位日期，也不显示“尚未解锁”文字；其徽章继续使用现有暗处理。解锁日期使用辅助文字色和 12px 字号，不新增彩色文字、胶囊或卡片表面。

对于复合条件，详情必须显示完整条件，不能只显示单个数值。例如：

```text
伤害 ≥ 12,000，承伤 ≤ 8,000
2026.07.23 解锁
```

### 删除内容

详情页底部删除以下区域：

- “当前”指标。
- “当前等级”指标。
- “下一等级”或“最高等级”指标。
- 底部进度条。

删除后不使用新的摘要卡片填补空间。通过三级徽章区和留白形成完整布局，保持当前深炭黑陈列面与细分隔线。

## 数据契约建议

成就结果不应继续由前端从赛季战报 DTO 临时拼装。建议后端提供独立的生涯成就查询，返回已经完成计算的成就列表：

```ts
type CareerAchievement = {
  key: string;
  title: string;
  detail: string;
  currentLevel: 0 | 1 | 2 | 3;
  tiers: [CareerAchievementTier, CareerAchievementTier, CareerAchievementTier];
};

type CareerAchievementTier = {
  level: 1 | 2 | 3;
  requirement: string;
  unlockedAt: number | null;
};
```

- `requirement` 是后端按成就规则生成的稳定中文条件，支持复合条件和段位条件。
- `unlockedAt` 使用 Unix 时间戳，与对局 `begin_ts` 口径一致；前端只负责格式化为 `YYYY.MM.DD 解锁`。
- 未解锁等级的 `unlockedAt` 必须是 `null`。
- DTO 不包含账号凭据、玩家隐私 ID、原始 payload 或真实用户数据 dump。
- 若需要证据跳转，可在后续计划中复用现有最小化 `EvidenceLink`，本设计不要求在详情新增证据按钮。

## 异常与空状态

- 没有任何已导入对局时，成就页显示既有中文空状态，不渲染虚假的零值解锁日期。
- 某项成就所需字段在所有对局中均缺失时，该成就保持未解锁；页面仍可显示三级条件。
- 单场记录存在部分字段时，只排除依赖缺失字段的成就，不影响其他成就。
- 时间戳无效时不得显示当前日期；该等级的解锁时间返回 `null`，并记录匿名诊断计数，不打印对局 ID、路径或 payload。
- 全部日期按本地时区格式化为自然日，不显示具体时分秒。

## 验收标准

### 规则

- 10 项新增成就的三级阈值与本文一致。
- 所有成就跨已导入赛季统计，切换或删除 URL 中的 `season` 不改变结果。
- 单局型成就不能把不同对局的多个条件拼接成一次达成。
- 每十分钟型成就排除不足 5 分钟或缺少有效时长的对局。
- 累计型成就按唯一对局累计，重复同步不增加进度。
- 好友对局一场最多累计一次。
- 段位成就使用标准化段位顺序，任一职责达到门槛即可解锁。
- 每个等级的日期等于当前已导入记录中首次满足条件的对局日期。

### UI

- 成就页没有赛季选择器，也不使用 `season` 查询参数。
- 详情顶部只显示成就名称和关闭按钮。
- 详情不显示当前值、当前等级、下一等级、最高等级或进度条。
- 每个已解锁等级在完整条件下显示 `YYYY.MM.DD 解锁`。
- 未解锁等级不显示日期，徽章保持暗处理。
- 二级和三级已解锁徽章继续显示对应紫蓝、金色动态光效；一级无动态光效。
- 成就墙悬停状态和详情页无选中浅灰底行为保持现状。

### 兼容与安全

- SQLite 变更必须提供幂等前向迁移和升级库测试。
- 同一账号重复同步得到稳定结果，不跨账号或跨数据库混合成就。
- 构建资源与 DTO 不含 token、cookie、authorization、credential、浏览器 profile 或真实用户数据。
- 测试只使用合成 fixture。

## 非目标

- 本轮不设计云端成就同步、账号间成就合并或跨设备永久账本。
- 本轮不修改徽章等级配色和动态光效规则。
- 本轮不在成就墙卡片增加解锁日期、进度或当前数值。
- 本轮不根据玩家职责、英雄或段位动态调整固定阈值。
- 本轮不通过百分位或全体玩家分布动态改变阈值。

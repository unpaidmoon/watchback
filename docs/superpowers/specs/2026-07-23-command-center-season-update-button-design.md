# 指挥台单赛季更新按钮视觉增强设计

## 背景

指挥台“已同步数据”表格中的单赛季“更新”按钮使用通用 `ghostButton`。当前按钮背景与表格行背景接近，且指挥台样式只设置了 `border-color`，没有形成可见边框，导致按钮与背景融为一体。

## 目标

- 让每行“更新”按钮在常态下可被快速识别为可操作控件。
- 保持次级操作层级，不与“同步一个赛季”等主操作竞争。
- 沿用现有颜色、圆角、间距与焦点规范，不引入新的视觉语言。
- 不改变表格布局、按钮文案、同步逻辑或可用性判断。

## 方案

仅增强 `.syncedSeasonUpdateButton`，不修改全局 `ghostButton`：

- 保持现有 `80px` 宽度、`44px` 最小高度和内边距。
- 使用 `var(--surface-control)` 作为浅灰绿背景。
- 增加 `1px solid var(--border-subtle)` 细边框。
- 使用 `var(--text-primary)` 作为文字颜色。
- 悬停时在现有表面上混入少量主文字色，使反馈清晰但克制。
- 禁用时使用不可点击光标与降低透明度，同时保留可读文案。
- 保留现有 `2px` `var(--data-primary)` 键盘焦点外环。
- 交互过渡只作用于背景、边框、颜色和透明度，持续时间遵循现有规范。

## 影响范围

仅涉及：

- `apps/owstats-desktop/src/styles/features/command-center.css`
- 对应的前端样式回归测试

不涉及 React 组件结构、Tauri 后端、同步 API、SQLite 或真实运行时数据。

## 验证

- 回归测试确认按钮具有浅灰绿背景与完整细边框。
- 回归测试确认悬停和禁用状态存在。
- 运行前端测试与构建。
- 运行 `git diff --check`，并核对工作树只增加本任务预期改动；用户原有未提交修改保持不动。

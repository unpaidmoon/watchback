# 战报威能图标底板视觉修复设计

## 目标

解决战报页“普通对局 · 威能”排行中白色威能图标与浅色背景重合、轮廓不清的问题。

## 设计

- 仅调整普通对局威能图标容器，不改变角斗异能和装备图标。
- 保持现有 `32px × 32px` 容器、图标尺寸、间距和直角外观。
- 威能图标容器使用纯白背景和 `1px` 灰色描边。
- 灰色描边复用现有 `--glass-border` 视觉令牌，不引入新颜色、阴影或圆角。
- 通过威能专属修饰 class 限定作用范围。

## 实现边界

- `ChoiceRankingsPanel.tsx` 根据 `kind === "perk"` 为图标容器添加威能专属 class。
- `shared.css` 为该 class 声明白色背景与灰色描边。
- 更新现有战报选择排行契约测试，验证专属 class 和样式均存在。

## 验收

- 普通对局威能图标显示在白色底板上，外围有细灰色描边。
- 角斗异能和装备图标样式保持不变。
- 排名布局、图标尺寸、文本和统计数据不发生变化。
- 前端测试与构建通过。

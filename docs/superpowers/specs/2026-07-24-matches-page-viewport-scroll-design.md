# 对局页视口滚动修复设计

## 问题

对局页已经让左侧列表与右侧详情分别滚动，但页面外层的高度链没有完全约束在当前视口内。最右侧整页滚动条因此还能继续向下滚动，并在工作台下方露出大面积空白。

## 目标

- 对局页固定在当前窗口的可用高度内。
- 对局页不产生整页纵向滚动条。
- 左侧对局列表与右侧详情继续独立纵向滚动。
- 不影响其他允许整页滚动的页面。

## 实现

仅调整对局页作用域内的布局 CSS。让 `.appFrame`、`.appCanvas`、`.matchesPage` 与 `.matchesWorkbench` 组成连续且可收缩的高度链，在对局页的 `.appCanvas` 上约束外溢，并仅在存在 `.matchesPage` 时锁定根页面滚动。工作台的左右面板继续使用 `overflow-y: auto`，组件结构和数据逻辑保持不变。

不采用全局 `body` 禁止滚动，也不修改所有页面共用的外层滚动策略，避免长内容页面被截断。

## 验证

1. 新增布局契约测试，要求对局页画布可收缩且不会把页面外层撑高。
2. 先确认测试在现有实现上因缺少约束而失败。
3. 实施最小 CSS 修复并确认测试通过。
4. 运行前端测试、前端构建与 `git diff --check`。
5. 使用合成 fixture 检查对局页：窗口最右侧无整页滚动，左右面板可独立滚动。

## 边界

- 不修改对局数据、同步、缓存或详情加载逻辑。
- 不新增颜色、字体、圆角、阴影或卡片语言。
- 不读取或输出真实凭据、真实用户数据或本地 SQLite。

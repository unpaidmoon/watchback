# 角斗汇总卡片不透明表面与正方形异能图标设计

## 目标

- 汇总卡片使用完全不透明的浅灰绿色表面，底层页面内容不可透过卡片看见。
- 异能槽固定显示为 `44px × 44px` 正方形，并保持四槽左对齐。
- 装备槽继续使用现有圆形样式。

## 实现范围

仅修改 `apps/owstats-desktop/src/styles/features/matches.css` 中汇总弹窗及异能槽的样式：

- `.phase7SummaryDialog` 使用与现有 `--glass-primary` RGB 基色一致的实色 `#f4f6f0`。
- `.phase7SummarySlots.trait` 使用四个固定 `44px` 列，避免可用空间将异能槽拉宽。
- 不修改弹窗结构、数据处理、交互、装备图标或其他角斗页面。

## 验证

- 在 `scripts/arenaPlayerRoundSummary.test.tsx` 中增加样式契约，先验证旧样式不能满足契约，再实施最小样式修改。
- 运行角斗汇总卡片专项测试、完整前端测试、前端构建与 `git diff --check`。
- 检查最终工作树只新增或修改本任务预期文件，并保留用户已有改动。

## 验收标准

1. 汇总卡片区域完全遮挡底层内容。
2. 四个异能槽均为 `44px × 44px` 正方形。
3. 装备槽继续显示为圆形。
4. 现有汇总卡片交互和响应式布局不回退。

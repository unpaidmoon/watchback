# 成就等级高光设计

## 目标

为成就墙与成就详情补充等级高光，使二级、三级成就具有清晰且稳定的等级辨识，同时保持未激活和一级成就的克制表现。

## 视觉规则

- 二级统一使用紫蓝色高光，三级统一使用金色高光，不从单枚徽章图片动态取色。
- 高光由透明图片光效与 CSS 暗角共同构成，光线从徽章中心向外扩散，包含克制的射线、粒子和快速衰减的边缘暗角。
- 二级使用平稳的紫蓝呼吸光与极慢射线旋转；三级使用金色呼吸光，并增加少量火花闪烁。
- 高光不改变文字颜色，不引入新的卡片尺寸、圆角或布局位移，不覆盖文字区域。
- 未激活和一级成就不显示高光。
- 未解锁等级继续沿用现有灰度、降饱和度和降低亮度的暗处理。
- 高光不得削弱正文和辅助文字的可读性。

## 光效资源

- 新增二级与三级透明 WebP 光效资源，各自包含主光晕、放射线和少量粒子纹理，不包含徽章、文字或卡片背景。
- 资源应置于受版本控制并由 Vite 正式打包的前端资源目录，不得引用生成目录、临时目录、`D:\\Codex`、`/@fs/` 或其他开发机绝对路径。
- 组件使用独立装饰层叠加光效资源；装饰层必须设置 `pointer-events: none`，不得影响卡片点击、焦点或详情关闭交互。
- 使用 `mix-blend-mode: screen` 或等价的亮色合成方式，并保留 CSS 径向暗角作为资源加载失败时的静态回退。
- 正式资源需裁切透明空白、使用合理尺寸并压缩，目标为单张约 50–150 KB；若视觉质量与该目标冲突，以不出现明显色带和锯齿为先。

## 成就墙交互

- 每张成就卡片根据当前等级获得明确的 `tier-0`、`tier-1`、`tier-2` 或 `tier-3` 状态类。
- 当前等级为二级时，鼠标悬停卡片显示紫蓝色背景高光。
- 当前等级为三级时，鼠标悬停卡片显示金色背景高光。
- 高光在约 180ms 内淡入；保持悬停或键盘焦点时，二三级光效分别进行缓慢呼吸，三级额外显示少量火花闪烁。
- 未激活与一级卡片悬停时保持现有背景，不显示等级高光。
- 键盘焦点与鼠标悬停提供等价的等级高光反馈，保留清晰的可见焦点状态。

## 成就详情行为

- 详情中的每个等级展示区域继续根据解锁状态标记为 `unlocked` 或 `locked`。
- 已解锁的二级等级区域常驻紫蓝色高光；已解锁的三级等级区域常驻金色高光，不要求鼠标悬停。
- 常驻高光使用与成就墙相同的呼吸、射线和三级火花动画，但动画范围限制在对应等级展示区域内。
- 一级即使已解锁也不显示高光。
- 未解锁的二级、三级区域不显示高光，并保持暗处理。
- 当前等级的既有语义可继续保留，但不得让未解锁等级因 `active` 状态获得高光。

## 实现边界

- 复用现有 `AchievementCard`、`AchievementDialog`、`currentLevel` 和等级循环，不修改成就计算、阈值、资源路径或数据结构。
- 通过组件输出稳定的等级类名和装饰性光效层，并在现有成就样式文件中定义显示条件、合成与动画。
- 呼吸周期控制在约 2.8–3.6 秒，射线旋转应明显慢于呼吸；仅动画 `opacity` 和 `transform`，避免布局、重绘热点和交互抖动。
- 同屏多个成就不得各自创建 Canvas、WebGL 上下文或透明视频解码器。
- 在 `prefers-reduced-motion: reduce` 下停止呼吸、旋转和粒子闪烁，只显示对应等级的静态光效。
- 用户可见文本不变。

## 验证

- 先扩展成就墙契约测试，覆盖卡片等级类、光效装饰层、二三级悬停/焦点显示，以及详情中已解锁二三级的常驻光效。
- 测试应明确约束未激活、一级和未解锁等级没有高光。
- 资源测试应确认二三级 WebP 被正式打包，并拒绝绝对路径与临时生成目录依赖。
- 样式契约应确认 `pointer-events: none`、仅合成属性动画和 `prefers-reduced-motion` 静态降级。
- 运行成就墙相关测试、完整前端测试、前端构建与 `git diff --check`。
- 视觉检查至少覆盖二级、三级、一级和未激活四种成就墙状态，以及详情中解锁与未解锁等级并存的情况。

## 非目标

- 不修改现有成就徽章图片；新增资源仅为可复用的透明光效层。
- 不改变成就墙卡片内容、布局、详情信息或等级判定。
- 不为未激活、一级或未解锁等级增加高光。
- 不使用 WebM、Canvas、WebGL 或运行时生成粒子。

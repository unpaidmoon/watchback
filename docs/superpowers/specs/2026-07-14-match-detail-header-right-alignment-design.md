# 对局详情头图右侧信息重排设计

## 目标

删除对局详情头图的“上一场 / 下一场”功能，将地图名称、比分、模式、时长和开始时间统一放在地图背景右侧，并按参考图形成清晰的右对齐三层信息结构。

## 范围

- 覆盖共享 `MatchDetailHeader` 的所有调用：工作台普通详情、工作台角斗详情和独立普通详情。
- 左侧结果斜切块、地图背景、胜利浅绿色以及失败/平局浅灰色保持不变。
- 不调整对局列表选中逻辑、角斗回合选择、队伍数据、筛选或详情加载。

## 结构

- 完整删除 `hasPrevious`、`hasNext`、`onPrevious`、`onNext` 组件属性及调用方传参。
- 删除头图中的相邻对局导航节点和对应 CSS。
- 地图侧只保留一个右对齐信息组，顺序固定为：
  1. 地图名称。
  2. 比分。
  3. 模式、时长、开始时间。
- 工作台不再为头图计算或维护上一场、下一场目标；对局切换仍通过左侧列表完成。

## 视觉

- 地图名称：白色粗体，约 `22px`，单行省略。
- 比分：白色粗体，约 `30px`，使用等宽数字。
- 元信息：低亮白色，约 `13px`，顺序为模式、时长、开始时间。
- 信息组贴近头图右侧内边距，整体右对齐；不新增颜色、字体、阴影、圆角或渐变。
- 窄屏继续右对齐，元信息允许换行，不覆盖左侧结果块。

## 数据与错误状态

- 继续使用现有 `mapName`、`score`、`modeLabel`、`duration` 和 `startTime`，不新增接口或状态。
- 地图名、比分或时间缺失时沿用现有格式化结果，不创建新的隐私标识或 GUID fallback。
- 地图图片加载失败时保持现有表面与反色文字可读性。

## 验收

- 头图中不再出现“上一场”“下一场”按钮、导航节点或相关 props。
- 工作台不再计算或传递相邻对局导航状态。
- 普通、角斗与独立普通详情均按“地图名 → 比分 → 元信息”右对齐显示。
- 元信息顺序为模式、时长、开始时间，字体层级接近参考图。
- 相关前端合同测试、完整 `npm test`、`npm run build` 与 `git diff --check` 通过。

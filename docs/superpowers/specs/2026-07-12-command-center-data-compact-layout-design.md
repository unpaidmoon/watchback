# CMD-DATA 数据操作紧凑布局设计

## 范围

仅调整指挥台 `CMD-DATA` 区域中的赛季数据状态卡。保持现有赛季选择、同步行为、数据字段和其他指挥台区域不变。

## 布局

在宽屏下，`本地对局`、`详情数`、`普通对局`、`角斗对局`、`待补详情`、`最近同步/导入` 六项事实以等宽的单行六列紧凑标签展示。每个标签保留中文标题和数值两级层次，降低内边距和文字尺寸以压缩卡片高度。

最近同步时间在该紧凑标签中显示为 `MM-DD HH:mm`；缺少时间时继续显示现有的中文兜底文案。详情覆盖率及同步页脚维持原位置和现有同步交互。

当可用宽度不足以容纳六列时，标签自动切换为三列，防止时间和值文本溢出。卡片的其他区块不改变。

## 实现边界

- 使用 `SeasonHealthPanel.tsx` 的现有 `DataFact` 结构，不增加接口、状态或后端改动。
- 以 `shared.css` 中的 `.phase8SeasonStatusStats` 及其子规则实现布局和紧凑样式。
- 仅为紧凑布局扩展 `phase6Shell.test.ts` 的源码级回归断言。

## 验证

先新增布局断言并确认其在旧样式下失败，再调整样式使其通过。随后运行该测试脚本、前端测试、前端构建、`git diff --check`，并检查工作区状态仅新增本任务预期文件。

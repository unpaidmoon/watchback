# Watchback 产品名称清理设计

## 目标

将 Watchback 确立为项目唯一的当前产品名称，彻底清除用户可见入口和当前维护文档中将 `OWStatsLocal` 或 `owstats-local` 作为现行产品名的表述。

本次清理不改变历史兼容标识，也不改写用于记录过去状态的历史资料。

## 名称规则

- 正式英文产品名为 `Watchback`。
- 中文功能说明保持为 `守望战绩工具`。
- 当前产品介绍、协作说明、视觉规范、开发状态和用户可见元数据不得再把 `OWStatsLocal`、`owstats-local` 或其他 `OWStats` 变体作为现行产品名称。
- 文件系统路径、命令和代码标识中的旧字符串不自动视为产品名残留。

## 修改范围

### 当前文档

以下类型的文档应统一使用 Watchback：

- 根目录 `README.md`。
- 根目录 `AGENTS.md`。
- 当前视觉规范 `design.md`。
- 当前开发状态、稳定化进度和主线程协作说明。
- Watchback 品牌设计中仍以旧产品名描述当前目标的句子。

文档中的真实工作目录和应用目录仍使用当前路径，例如 `D:\Codex\OW_data\owstats-local` 与 `apps/owstats-desktop`。这些内容是工程定位信息，不是产品展示名。

### 用户可见产品元数据

- Tauri `productName`、窗口标题和 WebView 标题继续使用 `Watchback`。
- Rust 包的用户可读 `description` 与 `authors` 改用 Watchback。
- 当前 UI、视觉验收 fixture 和用户可见错误或说明中不得出现旧产品名。

### 测试

品牌集成测试应明确检查主要用户可见入口使用 Watchback，并拒绝旧产品名。

测试必须继续允许兼容实现中出现旧字符串，不能通过全仓禁词断言阻止合法的兼容标识。

## 保留范围

以下名称作为历史兼容或内部工程标识保留：

- 仓库工作目录 `owstats-local`。
- 应用目录 `apps/owstats-desktop`。
- npm 包名、Rust package、binary、crate 和模块名。
- Tauri identifier `local.owstats.desktop`。
- SQLite 文件名、数据库路径和既有应用数据目录。
- Windows Credential Manager 中既有的 `OWStatsLocal` target 与用户名。
- API 字段名、上游协议字段、迁移常量和测试夹具中的兼容值。

保留这些字符串不代表继续使用旧产品名。

## 历史文档边界

旧设计规格、实施计划、工作报告和迁移记录中，若旧名称用于描述当时的产品状态、既有目录、兼容来源或原始命令，则保持原文。

当前仍被当作维护入口或执行依据的文档应更新现行产品称呼，但其中的历史事实和兼容标识不得改写。

## 实施方法

1. 使用精确搜索列出旧名称的全部出现位置。
2. 按“当前产品称呼、用户可见内容、兼容标识、历史记录”分类。
3. 只修改前两类，并更新相应品牌测试。
4. 再次搜索并逐项审查剩余命中，确认每一项都属于兼容标识或历史记录。
5. 运行受影响的前端测试、构建、Rust 格式检查和文本差异检查。

## 验收标准

- 应用窗口、HTML 标题、导航品牌区和其他用户可见入口只使用 Watchback。
- 当前项目说明和维护文档只把 Watchback 作为现行产品名。
- 旧名称的剩余命中均可归类为真实路径、内部标识、历史事实或兼容实现。
- 旧安装数据、数据库、凭据和升级路径不受影响。
- 未引入开发机绝对路径依赖，未接触或输出真实凭据和隐私数据。

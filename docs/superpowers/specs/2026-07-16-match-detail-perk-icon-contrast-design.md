# 对局详情威能图标对比度修复设计

## 问题

普通对局详情的威能 PNG 是透明底白色线稿：直接放在浅色玩家行上几乎无法辨认，而深炭色承托面又形成了突兀的黑色方块。

## 设计

- 仅调整 `.matchTeamTable` 内的威能缩略图，不影响角斗详情槽位。
- `.phase6PerkTooltip` 使用现有白色 `--surface-primary` 承托面和 `--border-subtle` 细边框。
- `.phase6CompactPerkIcon` 保持透明背景，将白色 PNG 线稿转换为浅灰色。
- 保持现有 `22px` 外框、圆角、排列间距和提示浮层行为。
- 普通对局详情的提示框从图标左边缘向右展开，最大宽度为 `min(300px, 60vw)`，长文本允许换行，避免越过详情滚动面板的左边界后被裁剪。
- 提示框标题使用 `--action-on-primary`，选择器必须高于玩家行通用 `strong` 规则，避免威能名称被覆盖成深色。
- 不新增颜色令牌，不修改图标资源。

## 验收

- 普通对局详情的威能图标呈白色背景、浅灰色线稿，不再出现黑色方块。
- 线稿仍可辨认，图标总尺寸和玩家行布局不变。
- 左侧威能的长名称与长描述完整显示，不被详情面板左边界裁剪。
- 威能名称在深色提示框上保持白色，与背景清晰区分。
- 威能提示浮层、无威能状态和角斗详情样式不变。
- 样式契约测试先因旧黑底失败，再在修复后通过。

# 对局列表四行信息与标签奖牌重设计

## 范围

仅调整 `apps/owstats-desktop` 对局列表卡片。不改变筛选、选择、详情打开、数据字段、地图缩略图或卡片外层视觉语言。

## 卡片信息结构

采用两层卡片结构：顶部为地图摘要横幅，地图仅作为视觉背景，承载胜负与比分；底部为个人数据区。地图名不在卡片内重复显示。此决策不采用参考图中的高饱和橙色、倾斜切角或强对比横幅，而沿用当前灰绿色画布与克制语义色。

摘要条固定高度为 `88px`。左侧约占横幅 `30%` 的结果块使用低饱和语义底色显示“胜利 2–0”（失败、平局使用对应的低饱和状态）。不显示地图名；地图横幅仅作视觉定位。摘要条下方的第一行显示“比赛模式 · 时间”，以避免模式重复。

结果块与地图横幅采用柔和渐隐过渡，不使用直线或斜切分界。

地图横幅全幅轻微去饱和，不额外压暗。

比赛模式/时间与英雄数据之间使用一条细分隔线，建立对局摘要与个人数据的边界。

个人数据行与评价行之间不再使用第二条分隔线，仅保留 `12px` 留白，以维持评价行的轻量感。

移除右侧进入详情箭头；整张卡保持可点击，不增加独立的箭头装饰。

信息层级固定为：

1. 88px 地图横幅：胜负与比分；地图只作背景，不显示地图名。
2. 个人数据区第一行：比赛模式与开始时间。
3. 个人数据区第二行：方形英雄头像、`K/A/D`，以及“伤害/治疗/抵挡”两组数据；不重复显示英雄名称，数值采用等宽数字。
4. 个人数据区第三行：对局主标签与奖牌。

标签和奖牌改为个人数据区内独立的第二行，用于本局评价，不与英雄头像和核心数据同行；不增加“本局评价”标题。评价行按“主标签 → 奖牌”排列，移除评分。

主标签使用中性细描边；奖牌保留极弱暖金/砖红细描边，仅用于奖牌语义，不形成色块。

第四行只承载评价信息，不能再与英雄信息或核心数据混排。页脚不再重复第 3 行数据。

## 标签与奖牌

采用“细描边标签”方案：

- 主标签使用透明底、低对比度 1px 描边、深灰文字；列表中不显示评分，不使用实心彩色胶囊。
- 奖牌使用同尺寸的圆形细描边图标，中文短文本保留在图标内。
- 正向标签与奖牌允许极弱暖金描边；负向奖牌允许极弱砖红描边；语义色不用于普通文字，也不形成色块。
- 四个项目以统一高度、8--12px 间距对齐到同一基线。没有标签或奖牌时保留稳定的第四行高度。

## 视觉与可访问性

遵循根目录 `design.md`：灰绿色画布、半透明浅表面、细分隔线、18--20px 外层圆角、无渐变和厚阴影。正文与数据保留黑灰层级，状态使用图标加中文文本；卡片按钮命中范围、键盘焦点和窄屏回退保持现有行为。

## 验收

- 一张普通对局卡片可清晰按四行读取，不出现英雄、标签和奖牌同列拥挤。
- 每行在 1440px 宽度下不换行；窄屏时允许第 2 行或第 3 行折为紧凑布局，但第 4 行仍独占一行。
- 标签和奖牌不再形成鲜艳色块，且胜负、标签、奖牌语义仍可区分。
- 保持现有测试、选择和详情跳转行为。

## 已确认的参考式横幅替代方案（2026-07-14）

- 顶部采用参考图同构的全宽地图横幅，而不是规则的左右网格：地图预览贯穿横幅，左侧炭黑结果块以前景叠层覆盖，并向右下形成斜切边缘。
- 横幅固定高度为 `64px`；结果块固定为横幅宽度的 `26%`，显示胜负与比分，地图名和比赛模式定位在地图右下，使用白色文字与阴影保障图片上的可读性。
- 不再显示对局时间、独立的模式/时间行或横幅下的分隔线。
- 下方固定为 `96px` 单行数据区：`64px` 方形英雄头像、`K/A/D`、“伤害/治疗/抵挡”、主标签与奖牌；不显示英雄名称、对局时间与评分。
- 结构复制参考图，颜色严格沿用 `design.md`：炭黑结果块、灰绿表面和低饱和语义描边，不引入参考图的高饱和橙蓝或深色整卡底。

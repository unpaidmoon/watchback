# 对局筛选器英雄与胜负位置交换设计

## 目标

将对局页面筛选器中的“英雄”和“胜负”交换所属位置，使英雄成为主筛选条件，胜负进入“更多筛选”。

## 可见顺序

- 主筛选栏：模式、英雄、玩家名称、更多筛选、清除。
- 更多筛选：胜负、地图、复盘标签、开始日期、结束日期。

## 行为约束

- 直接调整 React 组件结构，使视觉顺序、DOM 顺序和键盘焦点顺序一致，不使用 CSS `order` 制造仅视觉交换。
- 英雄继续写入 `filters.hero`，胜负继续写入 `filters.result`；URL 参数、选项来源、筛选 SQL 和有效筛选标签保持不变。
- “更多筛选”计数改为统计胜负，不再统计英雄；地图、复盘标签和日期计数规则保持不变。
- 不修改现有颜色、字体、间距、控件尺寸、响应式规则或其他筛选器顺序。

## 验证

- 更新筛选器组件合同测试，断言英雄位于主筛选栏、胜负位于更多筛选，并验证两者不会同时出现在错误区域。
- 更新更多筛选计数测试，断言英雄不计数、胜负计数。
- 运行筛选器针对性测试、完整前端测试、生产构建和 `git diff --check`。

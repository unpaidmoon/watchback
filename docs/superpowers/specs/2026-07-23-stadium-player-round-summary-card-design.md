# 角斗玩家回合汇总卡片设计

## 目标

在对局详情的“角斗汇总”视图中，为每位玩家提供跨全部实际回合的前端汇总卡片。用户点击玩家英雄头像后打开居中弹窗，按回合查看该玩家的回合开始资金，以及该回合结束时完整持有的异能和装备。

本功能仅在前端计算与展示，不修改 Rust 后端、SQLite、同步流程、上游原始数据或既有 DTO。

## 入口与交互

- 入口只出现在“角斗汇总”视图的队友与对手列表。
- 每个英雄头像是独立的可点击按钮。
- 点击头像打开对应玩家的居中汇总弹窗，不触发现有的整行展开。
- 整行点击和右侧箭头继续控制现有角斗玩家详情展开。
- 普通对局和角斗单回合视图中的头像行为保持不变。
- 弹窗支持右上角关闭按钮、点击遮罩和 `Esc` 关闭。
- 打开弹窗后焦点进入弹窗；关闭后焦点返回触发它的英雄头像。

## 弹窗布局

弹窗顶部标题栏同时显示：

- 主标题“汇总卡片”；
- 被点击玩家的英雄头像；
- 玩家名称。

内容区按对局实际存在的回合顺序显示 `R1`、`R2`，最多显示到 `R7`，不为不存在的回合补行。

每个回合固定为以下结构：

1. 回合标签；
2. 回合开始资金；
3. 四个异能槽；
4. 六个装备槽。

异能和装备使用固定槽位。已获得内容显示图标，尚未获得的槽位保留空位，使所有回合保持纵向对齐。卡片内不显示异能或装备名称、说明及悬停提示；图标仍提供必要的无障碍文本。

弹窗内容超过可用高度时，仅内容区纵向滚动。弹窗不增加横向滚动，也不改变页面的主要滚动容器。

## 数据计算

点击头像后，以目标玩家为关联对象遍历 `arena.rounds`，即时生成只读的前端汇总行模型。

### 玩家关联

- 优先使用现有 `bnetId` 在各回合内关联同一玩家。
- `bnetId` 缺失时回退到玩家名称。
- 关联标识只在前端内存中使用，不显示、不记录日志，也不加入新的 DTO 或事件载荷。

### 资金

- `R1` 的回合开始资金固定为 `3000`。
- `R2` 及以后优先使用上一回合该玩家的 `endWorth`。
- 上一回合 `endWorth` 缺失时，回退到当前回合该玩家的 `worth`。
- 两者都缺失时显示 `-`，不推算或伪造金额。
- 不使用当前回合的 `endWorth` 作为当前行的开始资金。

### 异能与装备

- 当前行异能使用当前回合玩家快照的 `traitGuids`。
- 当前行装备使用当前回合玩家快照的 `modGuids`。
- 两组数据均表示该回合结束时的完整持有状态，不计算增量。

### 缺失回合玩家

如果某个实际回合中找不到目标玩家，仍保留该回合对应的 `R` 行，避免回合编号断裂。该行资金按上述可确定的规则展示，异能和装备槽留空。

## 组件边界

实现分为三个职责清晰的单元：

1. 纯计算函数：接收目标玩家与全部回合，输出汇总行模型，集中处理玩家关联、资金错位和缺失数据。
2. 汇总弹窗组件：接收已计算的行模型，只负责标题栏、固定槽位、滚动和关闭交互。
3. 英雄头像入口：仅在角斗汇总视图注入打开弹窗的行为，并阻止点击事件冒泡到现有玩家行。

计算逻辑不写入 JSX，不修改后端返回结构，也不预先为未点击的玩家生成全局汇总数据。

## 视觉与资源

- 遵循根目录 `design.md` 的灰绿画布、低对比边线、圆角、阴影、间距和可访问性规范。
- 不引入新的品牌色、字体、圆角、阴影或嵌套卡片语言。
- 资金复用现有角斗资金图标，金额使用等宽数字。
- 英雄、异能和装备继续使用现有前端资源解析器。
- 资源无法映射时，遵循角斗 `traitGuids` 与 `modGuids` 的既有校对例外，在对应槽位显示紧凑的原始 GUID，不显示“待补充”文本；该例外不扩展到玩家、英雄或其他隐私标识。
- 支持 `prefers-reduced-motion`，弹窗不依赖非必要位移动画表达状态。

## 异常处理

- 缺失金额使用 `-`，不阻止弹窗打开。
- 某回合缺失玩家时保留回合行，异能和装备显示为空槽。
- 单个资源解析失败不影响其他槽位与回合。
- 汇总弹窗计算或渲染异常不得破坏现有角斗详情；关闭弹窗后原页面仍可操作。
- 所有新增用户可见文本使用中文。

## 验证

前端测试覆盖：

- `R1` 资金始终为 `3000`。
- `R2` 使用 `R1` 的 `endWorth`，而不是 `R2` 的 `endWorth`。
- 后续回合依次使用紧邻上一回合的累计资金。
- 上一回合 `endWorth` 缺失时回退当前回合 `worth`，再回退到 `-`。
- 每行使用当前回合结束时的完整 `traitGuids` 与 `modGuids`。
- 只生成实际存在的回合。
- 某回合找不到玩家时仍保留回合行。
- 四个异能槽和六个装备槽固定渲染。
- 卡片内不渲染名称、说明或悬停提示。
- 点击头像不会触发原有玩家行展开。
- 关闭按钮、遮罩、`Esc`、初始焦点与焦点返回行为正确。
- 普通对局和角斗单回合行为不变。

实现完成后至少运行：

```powershell
cd apps\owstats-desktop
npm test
npm run build
```

并在项目根目录运行 `git diff --check`，确认工作树只包含本任务预期修改和开始任务前已经存在的用户改动。

## 范围外

- 后端、SQLite、同步和导入改动。
- 跨对局保存或导出汇总卡片。
- 异能与装备增量计算。
- 异能与装备名称、说明或悬停提示。
- 普通对局或角斗单回合的新头像交互。
- 为不存在的回合补足到 `R7`。

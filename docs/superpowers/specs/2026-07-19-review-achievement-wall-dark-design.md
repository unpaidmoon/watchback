# 战报成就墙深色陈列面设计

## 目标

将战报“成就”标签中的成就墙与成就详情弹窗改为统一的深炭灰陈列面，使自带黑色圆底的成就徽章自然融入背景，同时保留战报页面其余区域的浅灰绿数据工具视觉。

## 设计依据

- 采用视觉对比稿中的 C 方案：整块成就墙深色，而不是在每张成就卡片顶部重复深色区。
- 深色只用于成就墙及其成就详情弹窗，不扩展到页面画布、标签导航或赛季选择。
- 使用现有深炭黑、灰绿、冷蓝绿色和黑灰文字体系，不引入新的品牌色、字体、圆角或阴影语言。
- 成就墙内部通过留白和细分隔线建立层级，避免“深色大卡套八张深色小卡”的嵌套卡片效果。

## 范围

- 调整 `PersonalReviewPage` 成就墙与成就详情弹窗的视觉样式及其对应静态视觉回归断言。
- 保留四列成就布局、八项成就顺序、徽章资源、等级、指标、说明、进度、证据链接和详情弹窗。
- 保留卡片点击、键盘焦点、悬停、未激活状态及现有响应式行为。
- 不修改成就计算、阈值、数据请求、URL 状态、页面导航或详情弹窗的数据、尺寸、遮罩与交互。
- 不修改徽章 PNG，也不通过混合模式、运行时滤镜或重新抠图去除徽章原有黑底。

## 视觉设计

### 外层成就墙

- `.phase6AchievementPanel` 使用现有 `--action-primary` 深炭黑作为主要表面，不使用纯黑、彩色渐变或明显高光。
- 保留外层主工作区的 `18-20px` 圆角和低对比细边线；阴影不得重于 `design.md` 规定的外层阴影。
- 标题使用浅色常规字重，不使用金色、彩色文字、强文字阴影或额外说明文案。
- 深色表面必须仅覆盖成就墙工作区，页面画布和导航保持现状。

### 成就项

- 每个 `.phase6AchievementCard` 改为透明背景、无独立阴影、无明显圆角边界。
- 宽屏四列布局使用 `1px` 低对比纵向与横向分隔线组织八项成就，不再为每项绘制完整卡片边框。
- 徽章保持现有尺寸和圆形资源显示；只允许使用克制的深色投影帮助金属细节离开背景。
- 主标题、指标、说明和下一等级信息改为深色表面上的三档浅色文字；正文对比度至少 `4.5:1`，辅助文字至少保持可辨识，不依赖颜色表达等级状态。
- 等级标记继续使用细边线小标签；不新增金色胶囊或彩色等级墙。
- 进度轨道使用低对比浅色透明底，进度填充继续使用 `--data-secondary` 冷蓝绿色。

### 状态与交互

- 悬停与键盘聚焦只轻微改变单项背景明度或产生不超过 `1px` 的位移，不恢复悬浮卡片阴影。
- 成就墙卡片的可见键盘焦点继续使用既有焦点色，并保证在深色表面上清晰可见；详情弹窗使用下述中性明度焦点状态。
- 未激活徽章继续使用现有灰度、饱和度和亮度处理；“未激活”中文状态必须保留。
- 证据链接必须在深色背景上满足可读性，并保留完整键盘命中区。

### 成就详情弹窗

- `.phase6AchievementModal` 使用与成就墙一致的 `--action-primary` 深炭黑表面、低对比浅色边线和规范内的外层阴影，不使用浅色页面表面、彩色渐变或强内高光。
- 标题、当前数据与等级使用 `--action-on-primary`；说明、阈值与标签使用两档降低透明度的浅色文字，正文对比度至少 `4.5:1`。
- 三级 `.phase6AchievementBadgeStage` 与底部 `.phase6AchievementModalStats .metric` 改为透明底、无独立阴影，通过 `1px` 低对比细分隔线组织，不形成“深色弹窗套浅色小卡”。
- 当前等级只使用中性浅色低透明度状态层与既有等级文字区分，不使用紫色、冷蓝绿色或其他彩色边线，不增加彩色普通文字。
- 详情进度轨道使用低对比浅色透明底，填充继续使用 `--data-secondary` 冷蓝绿色。
- 关闭按钮使用透明或低透明度中性浅色状态层与浅色关闭图标；键盘焦点通过可见的中性明度变化表达，不显示紫色、冷蓝绿色或其他彩色外环，命中区不得小于 `44px`。
- 遮罩强度、弹窗尺寸、打开关闭、Escape、焦点进入、焦点约束和关闭后的焦点恢复保持现状。

## 响应式

- `2540×1344` 与 `1920×1080`：保持四列，两行成就项通过连续细分隔线形成统一陈列网格。
- `1440×900` 及现有窄屏断点：保持现有两列规则，并重新计算分隔线，使换行后的首项不出现多余左边线。
- 不增加成就项高度，不引入内部滚动，也不改变页面唯一主滚动容器。

## 验证

- 更新成就墙静态视觉回归断言：外层与详情弹窗使用深炭黑表面，内部成就项、三级徽章区和指标区透明压平，进度保持冷蓝绿色。
- 运行 `reviewAchievementWall.test.ts`、`reviewVisualPolish.test.ts`、完整 `npm test` 和 `npm run build`。
- 在 `2540×1344`、`1920×1080`、`1440×900` 检查四列/两列分隔线、徽章与背景融合、深色详情弹窗、文字对比度、关闭按钮和键盘焦点。
- 使用匿名 fixture 或安全本地数据截图；不读取或输出真实凭据、隐私 ID、真实 SQLite 或真实数据 dump。
- 运行 `git diff --check`，并确认只提交本设计文档，不包含用户工作树中的既有改动。

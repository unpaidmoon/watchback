# Watchback 普通用户 README 设计

## 目标

将根目录 README 从开发期项目摘要改为面向普通用户的产品入口。读者无需了解 Tauri、Rust、SQLite 或仓库结构，也能快速理解 Watchback 的用途、功能、使用方式和本地数据边界。

## 内容结构

1. 产品简介：用简短中文说明 Watchback 是 Windows 平台的《守望先锋》本地数据分析桌面应用。
2. 功能亮点：介绍账号登录与赛季同步、对局浏览、对局详情、个人战报、排行、好友分析和角斗数据等现有能力。
3. 系统要求：说明当前以 Windows 为主要运行平台，并需要 Chrome 或 Edge 完成网易大神登录。
4. 安装与首次使用：在没有正式下载地址的前提下，只说明取得安装包后的安装、登录、同步和查看数据流程，不虚构下载链接。
5. 数据与隐私：说明数据主要保存在本机；不会把凭据主动复制到日志或无关数据结构；同步所得原始业务数据按上游内容保留。避免使用仅适合开发者的内部路径清单。
6. 常见问题：覆盖登录浏览器要求、凭据失效后重新登录、首次同步耗时和离线查看本地数据等用户关心的问题。
7. 开发者入口：将技术栈、构建、测试和发布细节压缩为指向维护文档的链接，避免干扰普通用户阅读。

## 表述边界

- 所有用户可见内容使用中文。
- 不宣称尚未验证或尚未提供的公开下载、自动更新、跨平台支持和安装体验。
- 不恢复旧的任意 BattleTag 绑定流程，也不描述 `searchBnetAccount` 等内部协议。
- 不写入真实账号、凭据、用户数据、开发机绝对路径或本地数据库内容。
- 保留 Watchback 品牌名称，删除旧名称与过时的开发期产品描述。

## 验收

- README 首屏能说明产品是什么、适合谁以及核心价值。
- 普通用户能按文档完成首次安装后的登录与数据同步。
- 数据保存和凭据边界表述准确，不与当前项目规则冲突。
- 开发命令不占据正文，仅通过维护文档提供给贡献者。
- Markdown 链接有效，`git diff --check` 通过。

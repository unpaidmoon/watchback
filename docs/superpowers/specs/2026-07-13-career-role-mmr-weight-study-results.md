# 生涯三职责 MMR：第一轮权重研究结果

日期：2026-07-13

## 结论

本轮拒绝将任何表现权重晋级到正式 MMR。生产模型继续保持
`performance_adjustment = 0`。

原因不是样本总量不足，而是当前数据不能把整场面板统计可靠地拆分到英雄或职责片段：

- 普通模式候选 1,808 场，全部可以形成胜负校准样本；
- 重装 728 场、输出 627 场、支援 453 场；
- 角斗 555 场全部属于 `Ambiguous` 口径，排除表现研究；
- 可确认的精确英雄时长为 0；
- 1,808 场 `healing_taken` 均无法区分自疗与队友治疗；
- 因此最终一击、伤害、治疗、减伤和资源债务暂时都不能进入训练。

离线投影强制将当前所有样本标记为 `outcome_only`，并关闭职责级和英雄级表现字段。

## 五折前向验证

评估使用五个严格向前的时间折。相同时间戳和时间范围重叠的比赛被合并成不可拆时间组件，所有折均满足：

```text
train_end_ts < validation_start_ts
```

验证窗口合计 1,506 场。当前 `expected_win_rate` 与固定 0.5 基线的整体结果：

| 指标 | 当前 expected | 固定 0.5 |
| --- | ---: | ---: |
| Brier Score | 0.248898 | 0.250000 |
| AUC | 0.555366 | 0.500000 |
| 10-bin ECE | 0.045783 | 0.025232 |

当前 expected 的区分力和 Brier 略好，但校准误差更差，不满足晋级门槛。

职责 AUC：

- 重装：0.564026
- 输出：0.549593
- 支援：0.545899

模式 AUC：

- 开放竞技：0.720209，验证样本 152；
- 职责竞技：0.718939，验证样本 115；
- 快速比赛：0.500000，验证样本 1,239。

快速比赛当前没有可用的赛前强度区分信号。竞技模式虽有区分力，但样本较少且 ECE 明显劣于固定 0.5，下一轮应先研究概率校准，而不是添加表现权重。

## S22 官方英雄分校准样本

用户提供的 S22 官方英雄竞技分截图只保留在仓库外，作为未来英雄级外部验证依据。截图未复制进仓库，玩家身份和逐英雄原始分数未写入代码、数据库或本文档。

当前训练投影没有可安全使用的英雄表现行，因此不能计算这些官方分数与模型英雄评分的相关性，也不能用它们反推职责权重。

## 下一步数据要求

满足以下任一条件后才重新启动表现权重拟合：

1. 上游提供按英雄分段的面板统计与英雄时长；或
2. 能确认职责锁定模式的整场统计不会跨职责，并为开放/快速模式提供可靠片段拆分；或
3. 提供明确的 `healingReceivedFromOthers` 字段，以区分外部治疗与自疗。

在此之前，最终一击正向权重和受到治疗资源债务都只保留为研究假设。

# AI 锐评输出恢复设计

## 问题

DeepSeek 请求成功后，模型输出仍可能因为代码围栏或某一条本地内容校验规则被拒绝。当前第二次请求与第一次完全相同，而且所有校验错误最终都映射为同一条“输出格式异常”，导致重试不能纠正具体问题。

## 设计

- 保持事实 ID、数字来源、身份、友好性和关系事实等安全校验不变。
- 解析前只兼容完整包裹 JSON 对象的 Markdown 代码围栏，不从混合文本中猜测或截取 JSON。
- 将本地校验错误映射为有限、匿名的修正指令；修正指令不得包含模型正文、事实内容、ID、路径或凭据。
- 首次校验失败后，第二次请求追加对应修正指令。HTTP、超时、长度、安全过滤和资源错误仍不重试。
- 第二次仍失败时继续返回既有用户可见错误，不扩大运行时日志或 DTO。

## 验证

- 合成响应测试代码围栏兼容。
- 合成服务断言第二次请求包含匿名修正指令且不回传第一次响应正文。
- 原有非法事实、数字、身份和攻击性输出测试保持通过。
- 真实验证只报告阶段、匿名结果和耗时，不输出请求、响应、ID、路径或凭据。

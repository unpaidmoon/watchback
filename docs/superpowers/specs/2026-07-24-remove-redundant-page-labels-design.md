# 删除冗余页面标签设计

## 目标

移除三个已确认不再需要的界面元素，并让相邻内容自然补位：

- 全局顶栏右侧的“本地数据”入口。
- 战报页面地图分析模块的“地图分析 / 地图表现概览”标题区。
- 指挥台页面右上角的“检查更新”按钮。

## 实现边界

- 直接删除对应 React DOM，而不是用 CSS 隐藏，避免保留空白、焦点或无效的可访问性节点。
- 清理因删除元素而不再使用的图标 import、回调与局部状态；若更新检查逻辑仅服务于该按钮，则一并删除该不可达逻辑。
- 更新直接断言这些元素存在的前端测试与视觉 fixture。
- 不修改其他“本地数据”状态文案、同步能力、地图数据内容或应用更新的底层后端实现。
- 不改动当前工作树中与本任务无关的用户修改。

## 验收

- 三处目标元素不再渲染，也不留下专属占位。
- 战报地图卡片或空状态直接承接模块内容区域。
- 相关前端测试、构建和 `git diff --check` 通过。
- 最终状态只包含本任务文件以及任务开始前已存在的用户修改。

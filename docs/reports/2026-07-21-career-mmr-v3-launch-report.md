# 生涯 MMR v3 个人表现模型上线报告

## 结论

生涯 MMR v3 已完成三级保证上线训练与运行时接入。现有数据没有产生满足一级平衡门槛的晋级候选，因此坦克、输出和支援三个职责均选择稳健百分位模型。该结果符合“约束学习 -> 强收缩 -> 稳健百分位”的保证上线设计，不回退到个人修正恒为 0 的 v2 模型。

## 三阶段结果

| 阶段 | 一级候选 | 结果 |
| --- | ---: | --- |
| screen（100 次） | 0 | 完成；进入保证兜底选择 |
| candidate（1,000 次） | 0 | 完成；无一级候选需要追加 bootstrap |
| final（10,000 次） | 0 | 完成；发布三级兜底 artifact |

零个一级候选表示现有样本没有通过约束学习模型门槛，不表示个人表现模型未启用。没有一级候选时，candidate 和 final 校验上一阶段完整性、重新执行投影与影子重放，并发布经过通用不变量校验的稳健百分位模型。

## 影子重放

| 指标 | 结果 |

| 重放比赛 | 4,251 |

旧层级模型的影子重放结果用于保持既有训练报告连续性；最终 percentile runtime 另行对全部 5,542 条可训练投影执行了运行时验收：5,322 条产生非零个人修正，非有限值 0、cap 越界 0、胜负方向反转 0。其中角斗竞技 1,072 条、角斗快速 39 条进入最终运行时检查。

运行时强制执行有限值检查、逐层级/逐模式 cap 和胜负方向保护。重复重放、事务失败回滚、v2 保留和 v3 唯一 active 已由合成集成测试覆盖。

## 发布接入

- 最终模型位于 `apps/owstats-desktop/runtime-config/career-mmr-v3.json`，由 Rust `include_str!` 编译进应用，不依赖开发机绝对路径或本地忽略文件。
- 手动重建和导入后的自动重建均调用正式 v3 入口。
- v3 artifact 在数据库写事务前验证；模型定义、事件、摘要和 active 切换在同一事务内完成。
- v2 数据继续保留，任何 v3 验证或重放失败都不会删除上一套完整结果。

## 训练性能说明

早期运行耗时异常的主因是使用 Rust debug 二进制执行数值训练。改用 release 二进制后，完整 screen 约 11.2 分钟，candidate 约 3 秒，final 约 2 秒。训练器同时将独立候选和 nested cell 并行化，并跳过已被前置门禁全部否决的 nested 重搜；统计次数、随机种子和门槛未降低。

# 生涯 MMR 设计报告

## 一、报告说明

生涯 MMR 是 OWStatsLocal 根据玩家本地保存的历史比赛数据，估算长期竞技水平的一项功能。它用于帮助玩家观察不同职责、不同赛季和不同模式下的长期变化。

该分数不是《守望先锋》官方段位，也不是暴雪服务器中的官方隐藏分。它是一套独立、透明、仅在本地运行的分析模型。

## 二、为什么需要生涯 MMR

游戏段位通常只反映某个赛季、某种竞技模式下的结果。赛季更新、定级场次、组队环境和比赛数量都会影响玩家看到的段位。

生涯 MMR 希望回答一个更长期的问题：如果综合玩家已有的全部赛季和多种比赛模式，这名玩家在某个职责上的稳定水平大约是多少？

因此，这项功能主要用于：

- 观察跨赛季的长期变化；
- 分别评估重装、输出和支援；
- 降低少量连胜、连败或异常对局造成的波动；
- 说明比赛结果、对手强度和个人表现可能带来的影响。

## 三、参考了哪些评分系统

设计过程中参考了《英雄联盟》《无畏契约》《Dota 2》《Counter-Strike 2》以及 TrueSkill 类评分系统。

这些系统虽然不会公开全部内部公式，但有几个共同原则：

1. 胜负是评分变化的主要依据；
2. 战胜更强的对手通常更有价值；
3. 长期稳定表现比单场高数据更可信；
4. 新玩家或比赛较少的玩家具有更高不确定性；
5. 个人表现只能辅助判断，不能取代比赛结果。

OWStatsLocal 没有直接照搬某一款游戏的算法，而是根据《守望先锋》的职责分工、英雄差异和现有数据重新设计。

## 四、使用哪些比赛数据

生涯 MMR 会动态读取玩家已有的赛季，不依赖固定赛季列表。当前纳入基础计算的模式包括：

- 职责竞技；
- 开放竞技；
- 角斗竞技；
- 快速比赛。

比赛结果、玩家职责、比赛时间、队友与对手强度会影响基础 MMR。不同模式的可信度不同，因此不会产生完全相同的影响。

角斗竞技具有多回合结构。为了避免累计统计和单回合统计混用，角斗数据只采用最后一个有效回合。

用于个人表现研究的数据还包括：

- 英雄使用时长；
- 消灭与最后一击；
- 助攻与阵亡；
- 英雄伤害、治疗和抵挡；
- 受到队友治疗量；
- 部分情况下可识别的承伤和目标贡献。

并非每场比赛都包含全部字段。缺失数据会保持为“未知”，不会被当成 0。

## 五、为什么三个职责分别计算

《守望先锋》的三个职责承担不同任务，不能使用同一套个人表现公式。

### 重装

重装通常承担开团、占据空间和吸收火力的任务。部分重装英雄具有很高的抵挡量，另一些英雄则依靠机动、控制或自我恢复生存。因此，高伤害或高抵挡不能单独代表优秀表现。

当前研究显示，重装职责中最后一击和阵亡是较稳定的核心信号，助攻只有较弱的正向影响。

### 输出

输出职责的主要任务是制造击杀机会并完成击杀。伤害量只有在转化为有效击杀和比赛优势时才具有更高价值。

当前研究中，输出职责的最后一击权重最高。助攻的影响接近于 0，而且在重复抽样中方向不够稳定，因此不适合作为固定加分或扣分项目。

### 支援

支援职责不仅负责治疗，还需要协助击杀、保持生存、提供增益或控制。不同支援英雄的治疗与伤害比例差异很大，所以不能只根据治疗量评价水平。

当前研究显示，支援职责的助攻具有较明显的正向价值，其重要性接近最后一击；阵亡仍然是较稳定的负向信号。

## 六、一场比赛如何影响 MMR

每场比赛按以下顺序处理：

1. 根据双方已有水平估算赛前胜率；
2. 根据胜、负或平局计算基础变化；
3. 按玩家在各职责上的实际使用时间分配变化；
4. 根据比赛模式和数据质量调整可信度；
5. 在通过安全验证后，才允许个人表现产生有限修正；
6. 对最终变化应用单场上限。

为避免单场异常比赛造成过大波动，每个职责单场最多变化 ±30。快速比赛的影响更低，单场最多变化 ±10。

这意味着，长期稳定取胜比某一场比赛刷出很高数据更重要。

## 七、用最近一场比赛说明

以下实例来自本地数据库中最近一场进入生涯 MMR 的比赛。为保护隐私，报告不展示比赛 ID、玩家 ID和其他玩家信息。

### 对局概况

| 项目 | 数据 |
| --- | --- |
| 赛季 | S23 |
| 模式 | 快速比赛 |
| 地图 | 皇家赛道 |
| 职责 | 重装 |
| 英雄 | 金驭 |
| 结果 | 胜利 |
| 比赛时长 | 9 分 31 秒 |
| 职责使用比例 | 100% |
| 数据质量 | 100% |

该局记录到的个人数据为：16 次消灭、7 次最后一击、0 次阵亡、11,912 点英雄伤害、2,066 点治疗、21,387 点抵挡，以及 13,124 点受到队友治疗。

### 第一步：确定预期胜率

快速比赛没有足够完整的双方段位数据，因此系统不能可靠判断哪一方更强。此时使用中立预期胜率 50%，而不是猜测队伍实力。

该局结果为胜利，因此结果值为 1：

`实际结果 - 预期结果 = 1 - 0.5 = 0.5`

### 第二步：计算基础变化

该局开始前，重装 MMR 为 2675.90，不确定度已经降到系统最低值 100。由此得到本场基础步长 10。

快速比赛权重为 0.5；该局全程使用重装，职责比例为 1；数据完整，质量系数为 1。因此：

`基础变化 = 10 × 0.5 × 1 × 1 × (1 - 0.5) = +2.50`

快速比赛单场最多变化 ±10，本场的 +2.50 没有触发上限。

### 第三步：检查个人表现修正

虽然该局取得了 7 次最后一击、0 次阵亡和较高抵挡量，但当前正式模型尚未启用个人表现修正。因此：

`个人表现修正 = 0`

受到队友治疗 13,124 点也没有被直接扣分。原因是重装本来就需要承受火力，而且现有数据不能证明这部分治疗资源应该按固定比例转化为加分或扣分。

### 最终结果

`最终变化 = 基础变化 + 个人表现修正 = +2.50 + 0 = +2.50`

该局结束后，重装 MMR 从 2675.90 上升到 2678.40。页面取整显示时，可理解为大约从 2676 上升到 2678。

这个例子说明：当前版本中，胜利使 MMR 上升；快速比赛的影响低于竞技比赛；完整使用某个职责时，变化全部计入该职责；个人数据会被保留用于研究和解释，但暂时不会额外改变正式分数。

## 八、为什么最后一击更重要

普通消灭可能由多人共同参与，而最后一击更接近一次击杀是否真正完成。与单纯伤害量相比，最后一击也较少受到持续输出、护盾攻击或英雄机制的放大。

在当前研究中，三个职责都选择了“最后一击权重为普通击杀参与的 1.25 倍”这一候选设置。该结果符合最后一击应当具有更高影响的设计目标。

但最后一击仍然只是辅助信号，不能代替比赛胜负。

## 九、如何看待“受到队友治疗”

受到大量队友治疗，说明玩家使用了较多团队资源。从理论上看，这些资源应当转化为生存、伤害、击杀或目标优势。

但是，这项数据不能直接用于扣分：

- 重装本来就需要承担更多火力；
- 不同英雄接受治疗的需求不同；
- 现有数据通常是整场统计，不能准确分配到每个英雄；
- 多英雄比赛中，不能把整场治疗量重复计算到每个英雄身上。

我们测试了直接扣分、英雄内归一化、超额治疗和资源转化债务等方案。完整测试没有得到足够稳定的非零权重，因此“受到队友治疗”目前不会影响正式 MMR。

## 十、如何减少英雄差异造成的误判

为了避免用同一个标准评价所有英雄，个人数据会先进行以下处理：

- 按英雄实际使用时间换算为每 10 分钟数据；
- 优先与同英雄、同模式、同赛季样本比较；
- 样本不足时，才逐步扩大比较范围；
- 使用稳健统计方法，降低极端对局的影响；
- 使用时间过短的英雄只保留胜负结果，不参与个人表现评价；
- 多英雄比赛不重复使用整场统计；
- 缺失字段保持缺失，不人为补成 0。

这些规则可以降低路霸与末日铁拳抵挡量较低、部分支援伤害较高等英雄机制带来的误判。

## 十一、算法经过了哪些测试

研究使用本地 SQLite 中的历史比赛进行只读测试，没有修改真实比赛数据。主要验证包括：

- 五折严格前向验证：只使用过去预测未来；
- 逐赛季留一：检查模型能否适应未参与训练的赛季；
- 逐英雄留一：检查模型能否适应未参与训练的英雄；
- 1,000 次按比赛重复抽样：检查权重方向和置信区间是否稳定；
- 五种“受到队友治疗”处理方案比较；
- 使用玩家提供的 S22 官方英雄竞技分作为外部方向参考。

完整评估覆盖重装、输出、支援与五种治疗策略，共生成 15 组候选结果。

## 十二、当前研究结论

测试结果表明：

- 胜负、最后一击和阵亡等核心信号具有预测价值；
- 三个职责确实需要不同的表现权重；
- 最后一击的影响稳定高于普通击杀参与；
- 支援职责中的助攻比其他职责更重要；
- “受到队友治疗”暂时不能形成稳定、可靠的扣分规则；
- 极端比赛中，仍可能出现某一个人数据对结果影响过大的情况。

因此，当前版本保留基础生涯 MMR，但个人表现修正继续设为 0。换句话说，现阶段正式分数仍以比赛结果、对手强度、职责使用时间和长期稳定性为核心，不会因为单场伤害、治疗或最后一击很高而额外大幅加分。

这并不表示个人数据完全无效，而是说明它还没有通过全部上线安全门槛。

## 十三、玩家应如何理解生涯 MMR

玩家在查看该分数时，需要注意：

- 它不是官方段位或官方隐藏分；
- 它是一项基于本地历史比赛的长期实力估算；
- 重装、输出和支援分别计算，不能简单横向比较；
- 单场高数据不会导致分数突然暴涨；
- 战胜较强对手通常比战胜较弱对手更有价值；
- 比赛较少时，系统会显示较低置信度；
- 长期稳定比赛比短期连胜或连败更能代表真实水平。

## 十四、隐私与透明度

生涯 MMR 在本地完成计算。研究和页面输出不会公开玩家隐私 ID、比赛 ID、登录凭据、令牌或原始比赛 JSON。

系统应尽量向玩家说明分数变化的主要原因，包括比赛结果、对手强度、模式、职责使用比例和置信度。数据不足时，应明确提示不确定性，而不是伪造精确结论。

## 十五、后续改进方向

后续研究将重点处理以下问题：

1. 增加更多赛季和英雄样本；
2. 限制极端对局中单一特征的最高贡献；
3. 改进输出职责的跨英雄覆盖；
4. 获取更精确的英雄级承伤和治疗承接数据；
5. 使用更多官方英雄竞技分进行职责内校准；
6. 重新验证个人表现修正是否满足上线门槛。

只有当个人表现权重在不同赛季、不同英雄和重复抽样中都保持稳定，并且不会让单一数据主导分数变化时，才会考虑逐步启用。

## 十六、总结

生涯 MMR 的目标不是给玩家贴上一个绝对标签，而是提供一条可解释、可持续观察的长期水平曲线。

当前设计坚持三个原则：胜负是基础、职责分别评价、个人表现谨慎使用。相比追求看起来精确的分数，我们更重视稳定性、公平性和透明度。

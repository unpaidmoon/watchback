# 生涯 MMR 个人表现模型训练报告

## 结论

本次使用正式只读训练程序，对本机已登记的两个匿名账号数据集执行了 `screen_100` 筛选。15 个“职责 × 实际模式”验证格全部判定为 `Shadow`，没有任何候选达到晋级条件。因此训练按计划停在筛选阶段，没有继续执行 1,000 次候选训练或 10,000 次最终训练，也没有启用个人表现修正、改写正式 MMR 事件或数据库。

这不表示个人表现与胜负完全无关。多数有数据的格中，候选模型的 Brier 分数和 AUC 有改善；但稳定性门禁没有同时通过。主要问题是关键系数的 95% CI 跨过 0、系数方向不稳定、部分参考系数退化为 0、资源转化债务系数没有稳定为负，以及 ECE、单特征贡献和封顶率超限。现阶段上线会把不稳定的相关性当成真实能力，因此结论是：**保留胜负基础分，不上线个人表现加减分，继续收集更均衡的数据后重训。**

## 五种受到治疗处理方案

本次对同一套职责特征同时比较五种方案，避免先主观指定“受到治疗一定应该扣多少分”。

| 方案 | 含义 | 本次通过格 |
| --- | --- | ---: |
| `None` | 不使用受到治疗修正，作为对照 | 0 / 15 |
| `DirectNegative` | 受到治疗越多，直接给予越强负向项 | 0 / 15 |
| `HeroNormalized` | 先按英雄与环境基线标准化，再计算资源占用 | 0 / 15 |
| `ExcessHealing` | 只惩罚超过合理预期的受到治疗 | 0 / 15 |
| `ResourceConversionDebt` | 将受到治疗与承伤、死亡、伤害和击杀转化一起建模 | 0 / 15 |

五种方案都使用逐折训练基线，验证折不会参与训练折的中位数、MAD 或治疗预期拟合，避免未来数据泄漏。多英雄普通对局不会把整场 `healingTaken` 粗暴复制或平均拆给各英雄。

筛选要求至少 4/5 个 forward 折改善；赛季留一至少 2 个有效组、英雄留一至少 5 个有效组，且覆盖率至少 80%、恶化组不超过 25%；账号留一必须覆盖已登记账号；bootstrap 至少完成 90%，关键方向稳定率至少 90%，Brier 差值 95% CI 上界必须严格小于 0。还要求 ECE 恶化不超过 0.005、单特征贡献不超过 35%、平均表现修正不超过 0.10 MMR、封顶率不超过 5%。这些条件必须同时满足，不能用某一个好看的 AUC 或 Brier 指标替代。

下表是筛选模型在有数据职责中的拟合系数范围。它们是预测胜率使用的原始 logit 系数，不是直接加减的 MMR 分数，也没有上线。

“最后一击权重大于普通击杀参与”的方向符合设计目标，但不能单独证明整个模型可靠。15 格均出现关键方向不稳定或参考系数退化；使用受到治疗的四种方案在每格都有关键 CI 跨 0，`ResourceConversionDebt` 的债务系数 95% CI 上界也没有稳定低于 0。因此不能把这些点估计值直接变成加减分规则。

影子重放覆盖两个匿名账号数据集，共计 3,140 场可重放的职责比赛：重装 746、输出 775、支援 1,619；上下限命中合计为 0。聚合报告没有输出可安全比较的“旧 MMR 与新 MMR 平均差值”，因此本报告不虚构该数字。由于候选未激活，正式持久化 MMR 与正式事件的实际差异为 0，正式数据库未被训练程序改写。

screen 报告、模型产物和 stage-commit marker 均由正式 CLI 在同一 diagnostics 目录原子发布，三者均完整且非空。写入前执行了模型边界、配置哈希、晋级报告结构和校验和验证；本次因候选数为 0，按计划没有调用下一阶段晋级训练。真实诊断 JSON 和模型保留在 app data，仅本 Markdown 聚合报告进入 Git。

## 上线结论与后续条件

本轮结论为 **不符合上线条件**：

1. 保留现有胜负基础分和模式权重；职责/开放竞技单场总变化继续限制为 ±30，快速与角斗快速继续限制为 ±10。
2. 不启用任何职责的个人表现修正，不把 screen 模型写成 active。
3. 后续优先补充角斗竞技、开放模式和非支援职责的数据，并增加独立账号数量；角斗快速仍不参与表现训练。
4. 重新训练时必须重新从 screen100 开始，只有出现候选才进入 candidate1000，只有候选阶段仍通过才进入 final10000。
5. 即使未来 final 阶段出现 `Eligible`，仍需经过用户单独确认，才能另行设计模型激活、迁移、回滚和 UI 状态。

本报告呈现的是实际失败结果，而不是为了上线而放宽门槛。当前数据证明“存在可预测信号”，但没有证明“这些信号稳定、公平且可安全转化为玩家单场 MMR 加减分”。
